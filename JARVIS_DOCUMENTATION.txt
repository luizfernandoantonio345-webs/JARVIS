🎮 COMO USAR
────────────────────────────────────────────────────────────────

INICIAR SISTEMA:
  cd C:\Users\cibernetico\JARVIS
  start_jarvis.bat

  Ou manualmente:
  Terminal 1: .venv\Scripts\python -m uvicorn backend.main:app --port 8000
  Terminal 2: cd frontend && npm run dev

CONTROLES:
  ESPAÇO          → Abrir/fechar input
  1-4             → Toggle widgets
  ESC             → Fechar tudo
  0               → Hide all

BOTÕES SUPERIORES:
  🤖 / ❤️          → Trocar tema (Jarvis / Iron Man)
  🎤              → Ativar reconhecimento de voz

DIGITAR COMANDO:
  • Sugestões aparecem automaticamente
  • Clique ou Digite Enter para executar
  • Orbe muda de cor (amarelo → verde)
  • Resposta toca em áudio (português)

HISTÓRICO (Widget 4):
  • Pressione 4 para abrir
  • Últimos 10 comandos
  • Hover = preview da resposta

TEMAS:
  • Clique em 🤖 para trocar
  • Tema salvo em localStorage
  • Persiste ao recarregar página

⚡ STACK TÉCNICO
────────────────────────────────────────────────────────────────

Frontend:
  - HTML5 + Canvas 2D (orbe + anims)
  - JavaScript vanilla (sem frameworks)
  - WebSocket (bi-direcional)
  - Web Speech API (voz)
  - localStorage (persistência)
  - CSS variables (temas dinâmicos)
  - Vite (dev server)

Backend:
  - FastAPI (Python 3.14)
  - WebSocket (uvicorn)
  - pyttsx3 (Text-to-Speech offline)
  - CORS habilitado
  - GZip compression

API Endpoints:
  WebSocket: ws://localhost:8000/ws/jarvis
  POST /tts: {text, lang} → {audio, format}
  POST /process: comando → resposta
  GET /health: status do sistema
